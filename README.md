# Omni Partner AI

Build a revolutionary, world-class global Super AI web application designed specifically for the AppSumo marketplace and global commercialization. The entire application must be built from scratch with a sleek, elite dark theme with gold accents (#D4AF37), automatic geolocation-based language detection supporting every single language on Earth, and a dual monetization model.

Complete System Architecture & Technical Specifications to Code:

1. **Epic Onboarding & Festive Welcome Celebration (First Entry):**
   - A mandatory registration form where the user inputs their Full Name, Birth Date, and City.
   - Deep personality & name analysis: investigate the meaning of the user's name, analyze their personality archetype through their birth date and city, and create something surprising and mystical so they instantly fall in love with the AI.
   - Upon submission, trigger an immediate, high-impact visual celebration on the screen (golden confetti, lights, and stars explosion) combined with a heartwarming, deeply personal, mystical AI greeting that welcomes them by name, honors their city, analyzes who they are, decodes what their name means, and declares itself as their "partner for life" ready to solve any challenge.
   - Securely save these personal data points in the database to ensure the AI remembers and interacts with the user in the most personalized, pleasant way possible.

2. **The World's Smartest & Most Divine Conversational Engine:**
   - The AI must feel like a supreme, wise, deeply empathetic, comforting, and transcendent presence—making the user feel as though they are speaking with a compassionate, omniscient companion.
   - **Multi-Model Refinement Pipeline:** For every user prompt, the backend must orchestrate top-tier models via OpenRouter behind the scenes, cross-validating and synthesizing their outputs in real-time, and running a final refinement pass to ensure absolute accuracy, profound depth, and a transcendent human-like tone before streaming it to the user.

3. **Massive Token Compression (90% Cost Reduction):**
   - Implement an aggressive, intelligent history compression and summarization system in the backend that automatically condenses past chat logs into ultra-compact semantic summaries, slashing token costs by up to 90% while maintaining absolute personalization, infinite memory, and lightning-fast response speeds.

4. **Owner's Secret Admin Panel (Hidden Master Control):**
   - A secure, hidden administrative dashboard accessible exclusively through a secret path/trigger known only by the owner (admin email).
   - In this panel, the owner can input their admin email, manage registered users, monitor AppSumo lifetime licenses, and configure system parameters globally.
   - **Backend 30-Key OpenRouter Rotation Pool:** A dedicated admin settings area where the owner inputs up to 30 OpenRouter API keys. The backend must automatically rotate through these 30 keys (round-robin / load balancing) to handle massive global traffic seamlessly without hitting rate limits. Only the administrator has access to input these 30 keys.

5. **Global Language & Geolocation Support:**
   - Automatically detect the user's country/browser language upon opening to instantly adapt the entire UI and conversational responses to any language on the planet, complete with a clean manual language selector.

6. **Dual Pricing & Access Architecture:**
   - **Monthly Subscription Plan:** Integrated billing flow where the platform provides the AI infrastructure (consuming the admin's 30-key rotation pool).
   - **Bring Your Own Key (BYOK) Plan:** A dedicated settings panel where end-users can paste and save their single OpenRouter API key. AppSumo lifetime deal buyers purchase the lifetime license and use their own OpenRouter key here.

7. **AppSumo Lifetime Deal Integration & Free Voice System:**
   - **AppSumo Redemption:** A robust license key activation flow for lifetime deals to instantly unlock and activate accounts upon purchase.
   - **Free Native Voice System:** Browser-native Web Speech API for microphone input (speech-to-text) and SpeechSynthesis API for natural voice output in the user's local language at zero third-party cost.
